# SuperNoteva releases

Release builds of SuperNoteva for macOS. This repository holds only the
built app and the file the app reads to learn of a newer version; the
source lives elsewhere.

- **Installing:** download the `.dmg` from the
  [latest release](../../releases/latest) and follow
  [INSTALLING.md](INSTALLING.md).
- **Updating:** an installed copy checks here on its own and offers to
  update itself.

These are test builds. Don't keep anything in them you can't afford to
lose.
